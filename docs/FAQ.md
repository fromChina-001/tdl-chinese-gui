# 常见问题与排查

返回 [README](../README.md) · [提交问题](https://github.com/fromChina-001/tdl-chinese-gui/issues)

## 安装器下载失败怎么办？

安装器会自动重试三次。仍然失败通常是当前网络无法访问 GitHub Release。

如果你正在使用支持 HTTP 代理的软件，请在项目目录打开 PowerShell，并按实际端口执行：

~~~powershell
powershell -ExecutionPolicy Bypass -File .\一键安装或更新.ps1 -Proxy 'http://127.0.0.1:7890' -Launch
~~~

不要直接照抄端口；7890 只是常见示例。也可以更换网络后重新双击安装器。安装器会校验官方压缩包的 SHA-256，校验失败时不会安装。

## Windows 提示“已保护你的电脑”怎么办？

从互联网下载的脚本可能触发 SmartScreen。请先确认下载地址确实是本仓库，并检查文件没有被第三方替换。确认后可在提示窗口选择 **更多信息 → 仍要运行**。

一键安装器会尝试解除本项目脚本和已校验 tdl.exe 的下载锁定。

## 双击两个启动文件都没反应

先双击 **一键安装或更新.bat**，确认 tdl.exe 已安装。之后优先使用安装器创建的 **Telegram下载器（中文版）.lnk** 或 **启动中文版下载器.vbs**。

如果窗口已经打开，重复启动会被阻止。请检查任务栏和其他桌面。

## 二维码一直不显示

- 确认已安装 tdl.exe。
- 如果当前网络访问 Telegram 需要代理，请在主窗口 **设置** 中启用代理。
- 地址需要带协议，例如 **http://127.0.0.1:7890**。
- 关闭登录窗口后重新点击 **登录 / 更换账号**。
- 如果旧会话失效，可在 Telegram 手机端的 **设置 → 设备** 检查并结束旧会话，再重新登录。

## “账号信息刷新失败”是否代表没有登录？

不一定。账号资料刷新使用一次轻量的 Telegram 请求；网络暂时不可用时可能失败。只要顶部仍显示检测到登录数据，可检查代理后点击 **刷新账号**。实际下载若提示登录失效，再重新扫码。

## 怎样复制 Telegram 消息链接？

通常可以在 Telegram 中右键消息或长按消息，然后选择 **复制消息链接**。不同客户端、群组类型和权限下入口可能不同。

如果客户端不提供“复制消息链接”，本界面无法只凭消息文字定位该消息。可以尝试：

- 使用 Telegram Desktop 打开同一条消息后再查看右键菜单。
- 让频道或群组管理员开启允许的分享方式。
- 使用可复制链接的公开频道消息。

本项目不会通过绕过 Telegram 限制来定位或恢复消息。

## 可以直接粘贴一整段文字吗？

可以。v1.1 会从文字中自动识别 t.me/.../消息编号 链接、去除常见的句末标点，并跳过同一批中的重复链接。点击 **加入下载队列** 或按 **Ctrl+Enter** 即可。

## 提示消息不存在或无权访问

请确认：

- 当前登录的是能够看到该消息的账号。
- 消息没有被删除，账号没有退出群组或频道。
- 复制的是单条消息链接，而不是群组邀请链接或频道首页链接。
- 私有群组链接中的消息编号仍然有效。

本项目不能绕过 Telegram 权限，也不能恢复服务器上已经不可访问的文件。

## 下载失败后怎么处理？

界面会按设置中的次数自动重试。仍然失败时：

1. 查看队列“结果”栏的中文提示。
2. 检查网络、代理和磁盘空间。
3. 选中失败项后点击 **重试选中项**。
4. 双击该项或右键选择 **打开 Telegram 原消息**，确认手机或桌面客户端仍可访问。

## 队列里的链接会上传吗？

不会。队列保存在本机项目目录的 gui-queue.json 中，并已被 .gitignore 排除。临时运行日志完成后会自动清理，界面日志也会隐藏完整 Telegram 链接。

提交截图或 Issue 前，仍请检查账号 ID、本地目录、代理信息和私有内容。

## 登录会话保存在哪里？

tdl 默认把会话保存在当前 Windows 用户目录下的 .tdl 文件夹。不要把这个文件夹、会话文件或验证码发给任何人。

怀疑会话泄露时，请立即在 Telegram 手机客户端 **设置 → 设备** 中终止对应会话。

## 软件能监控频道并自动下载新内容吗？

当前版本专注于“复制消息链接 → 加入队列 → 下载”，不包含频道监控。监控会涉及常驻运行、去重、权限和更高的账号风控风险，因此不会在没有充分测试的情况下默认加入。
